# Registro de cambios

Todos los cambios relevantes de este repositorio se documentan aquí. El formato sigue [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) y las versiones siguen [versionado semántico](https://semver.org/lang/es/): un cambio mayor para reestructuraciones de la guía, uno menor para capítulos o scripts nuevos y un parche para correcciones y actualizaciones de datos.

## [1.0.0] - 2026-11-20

### Añadido

- Guía en doce capítulos (`docs/00` a `docs/11`): principios, auditoría, inventario y plan, sistema de diseño, reconstrucción con bloques, plantillas con GeneratePress, SEO y redirecciones, rendimiento y caché, accesibilidad, verificación, trampas conocidas y qué no delegar en la IA.
- Checklist imprimible con reparto de tareas entre agente y persona.
- Cinco instrucciones de ejemplo para el agente.
- Scripts de verificación con Playwright: `axe-wcag.js`, `capturas.js`, `restos-elementor.js` y `redirecciones.js`, con pruebas locales (`npm test`).
- Fragmentos de código: arreglo del contenedor interno del Grupo, esqueleto de tokens, estilos en el editor y patrón de fragmentos PHP con guardas.
- Licencias CC BY 4.0 (textos) y MIT (código), `CITATION.cff` y `CONTRIBUTING.md`.

Versiones de referencia: WordPress 7.1, GeneratePress 3.6.1, GenerateBlocks 2.5.1, Elementor 4.4.1, LiteSpeed Cache 7.9.3, Rank Math 1.0.282, Code Snippets 4.1.0, Easy MCP AI 2.5.0 y especificación MCP 2026-07-28.
